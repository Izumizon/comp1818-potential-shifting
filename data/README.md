# Generated environment dataset

Run `python export_data.py` to regenerate the exact arrays. `environments.json`
records state encoding, actions, walls, start, goal, rewards and the collection
cap. NPZ fields are next-state tables, original rewards, true-terminal flags
and offline BFS distances. Distances are for evaluator diagnostics only, not
learner targets or inputs to graph smoothing.

`symbolic_baselines.json` and `bfs_*.npz` retain the actual informed planning
reference and its evaluation episodes. This diagnostic was added after the
primary suites, as recorded in the protocol addendum. It does not change the
prespecified contrast or confidence intervals.

The dataset was generated by the project code; no licence-restricted downloaded
training set is needed. Final learned Q-tables and potential arrays are stored
with each run under `results/`.
