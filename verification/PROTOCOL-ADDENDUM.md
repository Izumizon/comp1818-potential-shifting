# Post-run diagnostic addendum

After completing the frozen primary matrices, an informed BFS reference was
added to make the comparison with symbolic planning explicit. It uses the exact
transition graph and incurs no training. It is a task reference, not an
information-matched learning baseline, and is not included in the prespecified
extension contrast or confidence intervals. No primary run, outcome, seed or
condition was removed or retuned. The core plot was expanded to display the
already-collected unshaped baseline as well as all four shaping arms.

This addition helps assess whether learning is necessary for the fully known
toy navigation tasks; it does not establish real-world superiority of RL.
